YTPing-网络质量监控 · 使用说明
返回监控

本文介绍 YTPing 监控平台的主要功能与常见操作。默认访问地址：http://<服务器>:3000。
导航栏布局：刷新 · 批量启停 · 添加目标 · 更多（使用说明 / 定时任务 / 告警）· 主题 · 用户菜单。

登录与安全

  • 首次部署后使用默认管理员密码登录（请尽快在右上角用户菜单中修改密码，新密码至少 8 位）。
  • 登录失败连续 10 次将触发 10 分钟登录锁定，防止暴力破解。
  • 会话有效期 7 天；退出登录或修改密码后，所有旧会话立即失效。

监控目标

添加 / 编辑

  • 点击添加目标，选择探测类型并填写对应地址（端口包含在地址中，无需单独填写）。
  • 探测类型支持四种：
    • ICMP Ping：地址填域名 / IPv4 / IPv6（如 8.8.8.8 或 example.com）。
    • TCP：地址填 主机:端口（如 1.1.1.1:443），测量 TCP 握手延迟。
    • UDP：地址填 主机:端口（如 8.8.8.8:53），发送数据包等待回包，超时视为丢包。
    • HTTP(S)：地址填完整 URL（如 http://example.com），测量请求延迟，4xx/5xx 视为丢包。
  • 探测间隔：100ms～60s（默认 1 秒）。间隔越小采样越密，注意目标数量与数据库增长。
  • 可设置分组、标签（多个标签用英文逗号分隔），便于首页筛选与告警/屏蔽范围选择。
  • 卡片上显示 ID n 为系统内部编号，定时任务 / 告警 / 屏蔽「指定 ID」范围时使用。

卡片菜单

  • 卡片右上角 ⋮ 菜单：编辑、克隆（复制配置并自动命名）、启用/停用、删除。
  • 点击卡片进入详情页：实时、延迟趋势、丢包记录、历史统计。

首页看板

  • 顶部统计：正常 / 告警 / 异常 / 停用数量（基于近 1 分钟探测）。
  • 右上角时间左侧的告警状态指示（约 2 秒实时刷新）：● 红色圆点 = 告警中的告警数，● 蓝色圆点 = 已恢复未确认的告警数；点击圆点可直接跳转到「历史告警」页并按对应状态筛选。
  • 筛选：分组、标签、探测类型均支持多选（再点取消，点「全部」清空），可叠加关键词搜索；分组 / 标签 / 类型之间为「与」关系，同类内多选为「或」。
  • 卡片内20 格色块表示最近约 20 秒每秒探测结果（绿=正常 / 黄=告警 / 红=异常 / 灰=无数据）。
  • 均值延迟、丢包率标注为「近 1 分钟」；卡片显示探测类型徽标（ICMP/TCP/UDP/HTTP）。

详情页说明

  • 实时：近 5 分钟折线图，SSE 推送；显示最新延迟、5 分钟均值 / 最小 / 最大 / 丢包次数 / 丢包率。
  • 延迟趋势：1H～7D 快选或自定义时间范围，查看 Min/Avg/Max 与丢包率曲线及区间统计；停用期间以灰色标记（非红色丢包）。
  • 丢包记录：分页浏览历史丢包；连续丢包合并为一条记录并显示时间区间与次数。
  • 历史统计：超过 7 天的原始数据压缩为延迟分布桶（8 档）与丢包比例；可筛选时间并手动压缩更早的原始数据。
  • 所有弹窗（详情 / 添加编辑 / 批量启停 / 定时任务 / 告警 / 修改密码等）均支持点击外部空白处关闭。

批量启停

  • 导航栏 批量启停：对「当前筛选结果 / 全部 / 指定分组 / 指定标签 / 指定 ID」一次性启用或停用。
  • 停用后不再探测，适合夜间关机、维护窗口，避免无意义丢包入库。

定时启停

  • 按容器本地时间每天在设定时刻执行（建议配置环境变量 TZ=Asia/Shanghai）。
  • 范围：全部目标、分组/标签（可多选）、或指定 ID（逗号分隔，见卡片 ID）。
  • 可指定星期（0=周一 … 6=周日），典型用法：22:00 停用 + 08:00 启用 两条规则。

告警系统

导航栏「更多 → 告警」打开告警管理，含 4 个页签。

告警规则

  • 可创建多条规则，每条规则独立评估并产生告警记录。
  • 丢包条件：最近 N 个样本中丢包率 ≥ 阈值（%），或连续丢包 ≥ 次数，满足其一即触发。
  • 延迟条件：最近 N 个样本中延迟 ≥ 阈值（ms）的次数达到设定值即触发。
  • 样本窗口：评估使用的最近探测样本数（如 60 个）。
  • 范围：全部目标 / 分组（多选）/ 标签（多选）/ 指定 ID。
  • 重复提醒：0 = 仅触发时推送一次；>0 = 每隔 N 分钟重复推送直到恢复。
  • 生效时间（可多选组合，勾选的条件需同时满足）：① 生效时间（起止日期+时间）② 按天（周一到周日勾选）③ 按时段（每天起止时间，支持跨天）。不在生效时间内时规则不触发。
  • 故障解除后自动恢复，产生「已恢复」记录。

告警屏蔽

  • 在指定时间范围内屏蔽告警，支持按全部 / 分组 / 标签 / 指定 ID 选择目标。
  • 屏蔽期间仅停止邮件推送：告警仍会照常评估并写入「历史告警」，只是不发送通知。

历史告警

  • 可查看告警记录：规则、目标、状态、详情、通知次数，以及发生 / 恢复 / 确认时间；可按状态筛选（告警中 / 已恢复未确认 / 历史告警）。
  • 「已恢复未确认」的记录可点击确认归入历史告警；已确认（历史告警）的记录可反确认撤销或删除（删除不可恢复，仅历史告警状态可删）。
  • 排序：点击表头在升序 / 降序 / 取消间切换（时间 / 规则 / 目标 / 状态 / 详情 / 通知次数）。
  • 筛选：点击表头漏斗图标展开该列筛选框（时间列用日期时间选择器按区间筛选，文本列按内容筛选）。
  • 批量操作：勾选行复选框（表头可全选），支持批量确认 / 批量反确认 / 批量删除。

推送设置（邮件）

  • 配置 SMTP 服务器、端口、用户名/授权码、发件人、收件人及 TLS 开关。
  • 收件人支持多个，用英文分号 ; 分隔（如 a@x.com;b@x.com）。
  • 告警触发、恢复、重复提醒时向全部收件人发送邮件。

部署提示

  • 镜像需 --cap-add=NET_RAW 以支持 ICMP；数据目录挂载到 /data（如 -v /path/ytping:/data）。
  • 端口映射示例：-p 3000:3000。离线包导入与运行参数见项目 DOCKER-YTPING.md。
  • 仅暴露 Web 端口；数据库为容器内 SQLite 文件，无单独数据库端口。

界面主题

  • 右上角可切换深色 / 浅色主题，偏好会保存在浏览器中。
